# JSON Explorer

Paste JSON (a log line, an API response, a config) and explore it as a tree.

- **Fold** objects and arrays with a click; *Expand all* / *Collapse all*.
- **Search** keys and values: the tree keeps the matches and their parents.
- **Copy** a value's path (`$.items[3].price`) or the value itself.
- What you pasted is kept until you clear it.

Needs nothing but its own page: no network, no Claude, no tasks.
