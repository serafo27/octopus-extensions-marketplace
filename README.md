# Octopus extensions

A marketplace of Octopus extensions: add this repository in Octopus (Extensions › Marketplaces) to browse and install them.

Each extension is a folder in `extensions/` with a `manifest.json`, listed in `octopus-marketplace.json`.
To share one of yours: Extensions › Installed › your extension › Publish to… this marketplace, then commit and push.
Bump `version` in its `manifest.json` when you change it, so the others get it as an update.
